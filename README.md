**NEON TIDE — Port Azura** (v2, the harbour update): an original top-down 2D open-world crime game that plays in desktop Chrome from static files. Explore a seeded island city on foot, by car or **by boat**: steal cars (now including the Dune Pickup), run **eight story missions** for fixer Vera Castellan — the new one, *Salt Air*, sends you across the water to a yacht at anchor — earn cash, and dodge a heat-based wanted system: police interceptors and foot officers pursue by star level, and line-of-sight decides when the heat cools. Between jobs there are cab fares and **street races** — six-checkpoint sprints against the clock for cash. Fight with a mouse-aimed pistol, then earn Vera's **Kite SMG** (Q swaps guns, each with its own magazine). Port Azura now lives around the clock: a full dusk-to-night cycle with lit windows, glowing neon signs, lamp pools, headlight beams and police strobes; animated water with a foaming shoreline, piers, wakes and bow spray; gulls over the harbour and a plane that crosses the sky. Lane-following traffic, joggers and fleeing pedestrians, a live minimap with police and boat blips, synthesized WebAudio sound, and a localStorage save. Every name, character, building and line of art is original and drawn in canvas code; nothing is taken from any existing game.

## Run it

```sh
node serve.ts
```

Then open the printed local address in desktop Chrome. To build the hand-in output instead: `MAKEFUN_OUTPUT_DIR=out node main.ts`.

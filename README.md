**NEON TIDE — Port Azura**: an original top-down 2D open-world crime game that plays in desktop Chrome from static files. Explore a seeded island city on foot or by car: steal cars, run seven story missions for fixer Vera Castellan, earn cash, and dodge a heat-based wanted system — police interceptors and foot officers pursue by star level, and line-of-sight decides when the heat cools. Lane-following traffic, fleeing pedestrians, mouse-aimed pistol combat, a live minimap with police blips, a day cycle, synthesized WebAudio sound, and a localStorage save. Every name, character, building and line of art is original and drawn in canvas code; nothing is taken from any existing game.

## Run it

```sh
node serve.ts
```

Then open the printed local address in desktop Chrome. To build the hand-in output instead: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
